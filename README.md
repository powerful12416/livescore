# LiveScore 9SW ⚽ - Live Football HT/FT Scores

Fast, beautiful livescore with correct Lagos time (WAT).

**Live:** https://77.livescore-9sw.pages.dev
**Repo:** powerful12416/livescore

## ✨ Features
- Live / Results / HT / Table tabs
- Click Results → see HT: 1-0 | FT: 2-1
- Correct time on left side - WAT (Africa/Lagos) not UTC
- League grouping like Flashscore
- Daily Bible verse 🙏
- Mobile first design

## 📂 Files
- `index.html` - Main beautiful UI
- `functions/api/index.js` - API returning HT/FT with Lagos time fix

## 🔧 Setup
1. Go Cloudflare Pages > Settings > Environment Variables
2. Add `FOOTBALL_API_KEY`
3. Redeploy
